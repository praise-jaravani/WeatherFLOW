# Génevieve — Diffusion Model Scratch Space

This folder is yours. Génevieve's diffusion work (DiffSTG, USTD) has been
moved out of this repo — you're maintaining them in your own forks and can
pop them in via your integration approach of choice.

Use this folder for anything project-related that you want tracked in the
main WeatherFLOW repo:

- Integration scripts / notebooks
- Adapter drafts before they land in `models/diffusion/`
- Experimental scripts specific to your models
- Notes and analysis you want the team to see

**When you're ready to integrate a model back in**, see
`docs/TEAMMATE_INTEGRATION.md` §5 (Adapter Integration Guide) for the
exact BaseAdapter contract and adapter/model file layout.
